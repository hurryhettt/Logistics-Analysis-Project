# Logistics-Analysis-Project

**OBJECTIVE**
Determine the most optimal mode of transportation per origin port per service level assuming that orders are urgent

**METHODOLOGY**
Analyze the data using tableau dashboard

**CONCLUSION**

**Service level: DTD**
From port 2, the best transportation mode to use is air via carrier V444_4 with 1 day shipping time.
From port 3, the best transportation mode is ground via carrier V444_0 or V444_5 with 1 day shipping time.
From port 4, the best transportation mode is air via carrier V444_4 with 1 day shipping time.
From port 5, the best transportation mode is air via V444_4 with 1 day shipping time.
From port 6, the best transportation mode is air via carrier V444_4 with 2 days shipping time.
From port 7, the only transportation mode is air via V444_2 with 4 days shipping time.
From port 8, the only transportation mode is air which is best to take via carrier V444_6 with 2 days shipping time.
From port 9, the best transportation mode is ground via carrier V444_0 with same day delivery.
From port 10, the only mode of transportation is air which is best to take via V444_4 with 3 days shipping time.
From port 11, the only mode of transportation is air which is best to take via carrier V444_8 with 5 days shipping time.

**Service Level: DTP**
From port 2, the only mode of transportation is air via carrier V444_5 with 2 days shipping time.
From port 3, there’s no carrier that offers this service level.
From port 4, the only transportation mode is air via carrier V444_0 with 3 days shipping time.
From port 5, the only transportation mode is air via carrier V444_5 with 3 days shipping time.
From port 6, the only transportation mode is air which is best to take via carrier V444_4 with 2 days shipping time.
From port 7, the only transportation mode is air via carrier V444_2 with 5 days shipping time.
From port 8, the only transportation mode is air via carrier V444_2 with 5 days shipping time.
From port 9, the only transportation mode is ground which can be taken via V444_0 or V444_5 with same day delivery.
From port 10, the only transportation mode is air via carrier V444_2 with 3 days delivery time.
From port 11, the only transportation mode is air via carrier V444_2 with 5 days delivery time.
